An entry for [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) on [make.fun](https://make.fun).

The whole entry is one sentence — a pitch meant to convince a friend who has
never coded to let an AI agent build their first app idea. `main.ts` writes
that sentence to `entry.txt` in the output directory.

## The pitch

> That app idea you keep describing at dinner — say it in plain words on make.fun and an AI agent builds a first version you can tap through tonight, no code from you, just watching it take shape and pointing at what to fix.

## Run it

```sh
node main.ts
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (falling back to
`/output`). The program uses only the Node.js standard library and runs on
Node 22.18 or later.
